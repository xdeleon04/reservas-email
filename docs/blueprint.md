# **App Name**: Reservas Email

## Core Features:

- Email Based Reservation: User reserves the table by only entering a name, an email and preferred time. After reservation, the user will be redirected to their reservation details page.
- Email Reservation Review: User can review reservation using only email.
- Reservation Management: The administrator can see all the reservations and has permission to manage them.
- Table Management: The administrator can create, update, and delete tables.

## Style Guidelines:

- Primary color: Deep indigo (#4B0082) evoking elegance and reliability, suitable for restaurant setting.
- Background color: Soft lavender (#E6E6FA), desaturated to maintain a professional tone.
- Accent color: Muted magenta (#C71585), used sparingly to draw attention to key interactive elements.
- Body and headline font: 'Alegreya', a serif font which gives an elegant, intellectual, contemporary feel.
- Use simple, outlined icons from a set like Material Icons to represent actions such as 'edit', 'delete', and 'confirm'.
- Clean, minimalist layout with clear hierarchy and sufficient spacing to avoid clutter.
- Subtle transition animations for UI elements like buttons and forms to improve the user experience.
